# Good Tools

A collection of 50+ small everyday and developer tools that live in your Home Assistant sidebar.
Merge or split PDFs, shrink photos and strip GPS data, make Wi-Fi QR codes, share a clipboard between
your PC and phone, check YAML and cron expressions, and more. File tools run inside your browser, so
your documents and photos are not uploaded anywhere.

Home Assistant 사이드바에서 바로 쓰는 생활·개발자 도구 모음입니다. PDF 합치기, 사진 용량 줄이기,
와이파이 QR코드, 가족 공유 클립보드, YAML·크론 검사 등 50개 이상의 도구가 들어 있습니다.

See the **Documentation** tab for options, or the [project page](https://github.com/redchupa/ha_good_tools) for screenshots.
