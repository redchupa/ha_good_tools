# Changelog

## 1.0.0 (2026-11-24)

- **최초 릴리즈**: `wepplication/tools` 기반 32종 온라인 도구를 2026년 최신 웹 스택(React 19, TypeScript, Tailwind CSS v4, Node.js Express)으로 전면 업그레이드하여 Home Assistant 앱(Add-on)으로 출시.
- **일반 도구 19종**: 특수문자표, 아스키아트 생성(텍스트+이미지), GIF 생성기, 바코드/QR 생성기(Wi-Fi QR 포함), Markdown 웹 에디터, 자막 변환기(SMI/SRT/VTT + 싱크 이동), 글자수 세기, 한영타 변환기, 매직아이 생성기, TTS, EML 뷰어, 원주소 변환기, IP/DNS/CIDR 조회, 로또 번호 생성기, 화면 손전등(SOS/WakeLock), 우편번호 조회, 바코드/QR 스캐너(이미지+카메라), 파일 체크섬 조회(MD5/SHA/CRC32), STT.
- **개발자 도구 12종**: HTML 코드표, 아스키 코드표, 색상표 & WCAG 명암비 검사기, 이미지↔Data URL, 코드/문서 Diff 비교, 코드 정렬(JSON/JS/HTML/CSS/SQL/YAML), 코드 압축, 인코딩 & JWT 디코더, UUID v4/v7·ULID·NanoID 생성기, 키보드 이벤트 검사, 원격 HTML 소스 & 실시간 미리보기, AES-256/HMAC/비밀번호 보안 도구.
- **웹/피드 도구 1종**: CORS 우회 RSS/Atom 피드 리더 및 `/data/feeds.json` 영속 저장.
- **보안 & HA 통합**: Home Assistant Ingress 완벽 지원, SSRF 방어 프록시, 다크/라이트/시스템 테마, `Ctrl+K` 빠른 검색, 즐겨찾기 지원.
