# Changelog

## 1.6.1

- RSS, 공인 IP와 우편번호는 사용자가 조회할 때 연결합니다. 서버는 외부 요청 간격과 동시 연결을 제한하고 429·503 응답의 Retry-After를 존중합니다.
- Public lookups now run on demand, pace requests, reuse cached results and honor upstream cooldowns.

## 1.6.0

- 영어 설정을 도구 내부의 입력 안내, 버튼, 결과, 오류 메시지까지 확대했습니다.
- English mode now covers tool controls, input hints, results and error messages.

## 1.5.1 (2026-11-24)

- 1.4.1에서 고정 메모를 20개보다 많이 둔 경우, 업그레이드 후 메모를 저장하면 21번째부터의 고정 메모가 지워지던 문제를 고쳤습니다. 이미 고정된 메모는 모두 유지하고 20개 제한은 새로 고정할 때만 적용합니다.
- 공유 메모 삭제 확인을 브라우저 확인 창 대신 화면 안의 "삭제 확인" 버튼으로 바꿨습니다. 확인 창을 띄우지 않는 Companion 앱에서도 삭제할 수 있습니다.
- 파일 변환기를 닫으면 변환 결과가 차지하던 메모리를 바로 돌려줍니다.
- 인코더에서 한 글자짜리 ASCII Hex(예: `d55c` → 한)를 되돌릴 수 있고, 자동 감지가 일반 단어나 연도를 Base64·Hex로 잘못 판단하지 않습니다.
- 설정 저장에 실패하면 화면도 이전 상태로 되돌립니다. 네트워크 도구를 꺼도 IP 도구의 서브넷 계산기는 "일부 제한"으로 표시합니다. 이미지→PDF 준비 중 취소를 누르면 변환을 시작하지 않습니다.
- 좁은 도구 카드에서 "서버"·"지금 사용 불가" 표시가 한 글자씩 줄바꿈되던 문제를 고쳤습니다.
- README 화면 예시를 1.5 화면으로 바꿨습니다.

## 1.5.0 (2026-11-24)

**새 도구와 업그레이드**
- **파일 변환기**를 추가했습니다. PDF를 페이지별 JPG·PNG·WebP로 바꾸고(72·150·300 DPI, 페이지 범위, 비밀번호 PDF), 이미지 형식·크기를 변환하며(PNG·JPG·WebP·GIF·BMP·SVG, Safari의 HEIC), 이미지를 PDF로 합칩니다. 여러 결과는 ZIP으로 한 번에 저장할 수 있고 모든 처리는 기기 안에서 합니다.
- **인코딩 / JWT 디코더**를 입력·출력 형식을 고르는 변환기로 바꿨습니다. Plain·URL·HTML·Base64·Base64URL·ASCII Hex·Hex·8진수·2진수·10진수·Unicode·Gzip·Zlib·Deflate를 서로 변환하고, 입력 형식 자동 감지와 JWT 만료 시각 표시를 지원합니다. 잘못된 입력은 결과 대신 오류로 알려 줍니다.
- **공유 메모**를 수정할 수 있습니다. 다른 기기에서 먼저 바꾼 메모는 덮어쓰지 않고 알려 주며, 화면으로 돌아오거나 30초마다 새 메모를 불러옵니다.
- 지금 접속 환경(HTTP·HTTPS, 앱 설정)에서 쓸 수 없는 도구를 홈 카드와 도구 화면에 미리 표시합니다.
- HA 연동 권한이 없는 사용자에게 자신의 HA 사용자 ID와 등록 방법을 보여 줍니다.

**수정**
- 고정한 공유 메모가 새 메모 50개 뒤에 지워지고 새 메모 아래로 밀리던 문제를 고쳤습니다. 고정 메모는 20개까지 따로 보관합니다.
- HTTP로 접속하면 암호화 도구의 AES·SHA·HMAC이 동작하지 않던 1.4 회귀를 고쳤습니다. HTTP와 HTTPS 기기가 같은 암호문을 주고받을 수 있고 MD5·SHA-1·SHA-512도 다시 제공합니다.
- 여러 기기에서 즐겨찾기·숨긴 도구를 바꿀 때 서로 덮어쓰던 문제와, 첫 화면이 뜨기 전 변경이 서버 값을 지우던 문제를 고쳤습니다. 저장 실패는 화면에 알려 줍니다.
- 손상된 메모·피드·설정 파일 때문에 기능이 계속 오류를 내던 문제를 고쳤습니다. 원본은 `*.corrupt-<시각>.json`으로 보관하고 기본값으로 계속 동작합니다.
- PDF 페이지 미리보기가 Chrome과 Android 앱에서 비어 보이던 문제, 이미지→PDF에서 WebP 등이 실패하거나 큰 PNG가 메모리를 많이 쓰던 문제를 고쳤습니다.
- 취소한 뒤 같은 파일을 다시 고르면 반응이 없던 문제, 공유 링크로 연 뒤 새로고침할 때마다 같은 도구로 돌아가던 문제, 구형 HA의 공유 링크 경로를 고쳤습니다.
- 세미콜론(;) 구분 CSV를 인식하고, 환율 갱신 시 출처에 없는 통화(TWD·VND)를 알려 줍니다. LAN 포트 점검에서 HA 내부 네트워크(172.30.32.0/23)를 제외했습니다.

**배포**
- 같은 버전을 다시 게시하지 않도록 막고, 세 아키텍처 이미지를 각각 실행해 상태와 버전을 확인한 뒤에만 버전 태그를 만듭니다. 이미지가 없는 버전이 main에 들어가지 않도록 검사합니다.

## 1.4.1 (2026-11-24)

- 공유 링크가 현재 Home Assistant 앱 패널에서 지정한 도구를 바로 엽니다. 사이드바 표시 여부와 무관하게 사용할 수 있는 패널 경로를 사용합니다.

## 1.4.0 (2026-11-24)

- 체크섬을 1 MiB 단위로 계산하고 PDF 변환을 별도 Worker에서 실행합니다. 진행률·취소·페이지 미리보기를 지원합니다.
- HA 사용자 허용 목록을 설정하면 엔티티 검색이 열립니다. 템플릿 평가와 모바일 알림은 별도 옵션입니다.
- HTTPS에서 PBKDF2·AES-GCM과 Web Crypto SHA/HMAC을 사용합니다. 기존 CryptoJS 암호문 복호화를 유지합니다.
- 최근 도구 8개, 세션 토큰 없는 공유 링크, 영문 도구 설명, 기준일이 있는 환율 갱신, 룰렛 목록 보존 및 모션 감소를 추가했습니다.
- 검증한 웹 번들을 재사용하는 GHCR 패키징 워크플로를 추가했습니다.

## 1.3.3 (2026-11-24)

- 외부 URL과 SSL 진단 연결에 검증된 IP를 고정하고, 미리보기의 외부 리소스 요청을 제한했습니다.
- HA Ingress로 접속 경로를 통일했습니다. 기존 8099 직접 접속 사용자는 사이드바로 접속하세요. 신규 설치의 LAN 도구는 설정에서 켤 수 있습니다.
- 여러 기기가 동시에 수정할 때 공유 메모·설정·피드가 사라지는 문제와 저장 실패 시 서버 예외를 수정했습니다.
- 정규식 계산을 제한 시간 있는 Worker로 옮기고, CSV 따옴표와 여러 줄 셀, 크론 입력 검증과 HA 예시 생성을 수정했습니다.
- 다운로드·카메라·음성·이미지 리소스를 정리하고 대용량 파일 입력에 제한을 추가했습니다. 코드 정렬에는 Prettier를 사용합니다.
- 초기 번들을 축소하고 npm 잠금 파일 기반 멀티스테이지 빌드로 변경했습니다. armv7 런타임은 게시된 Alpine 3.22 베이스를 사용합니다.
